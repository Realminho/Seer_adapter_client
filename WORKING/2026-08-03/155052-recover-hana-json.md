# recover-scp-overwritten-hana-json

### 목표
- scp로 AMR의 hana.json을 직접 덮어쓴 경우의 복구 가능 경로를 확인한다.

### 지금
- 실행 중인 AMR 프로세스의 메모리/조회 경로에서 이전 맵을 내보낼 수 있는지 확인한다.

### 완료
- scp 직접 덮어쓰기는 어댑터의 setMap 백업 경로를 거치지 않음을 확인했다.

### 다음
- AMR을 재시작하지 않고 캐시/백업/스냅샷 순서로 복구 후보를 확인한다.

### 검증
- 로컬 Git에는 덮기 전 AMR 파일이 없고 hana2.json도 복구본이 아니다.
