# Guide

Audience: internal engineers, operators, and project members.

Use this directory for documents that help people understand, develop, operate, or troubleshoot the project.

Examples:

- Development setup
- Adapter operation guide
- Debugging workflow
- Deployment workflow
- Onboarding notes
- Internal troubleshooting checklist

Do not place customer-facing manuals here. Use `docs/manual/` for customer documents.
